Domain
======

Зарегистрированный пользователь выполняет упражнения (:term:`exercise`) по различным дисциплинам.

Упражнение “Тестирование”
~~~~~~~~~~~~~~~~~~~~~~~~~

При выполнении упражнения "Тестирование" (:term:`testing`) пользователю
показывается вопрос (:term:`question_text`) и варианты ответа (:term:`options`).

Возможен только один правильный ответ на вопрос теста.

Вариант ответа представляет собой номер варианта (:term:`option_value`)
и текста варианта ответа (:term:`option_text`).
