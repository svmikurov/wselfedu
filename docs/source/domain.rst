Domain
======

Описание упражнения
~~~~~~~~~~~~~~~~~~~

Зарегистрированный пользователь выполняет упражнения (:term:`exercise`) по различным дисциплинам.

Доступные дисциплины:
    - Глоссарий (:term:`glossary`)
    - Иностранный язык (:term:`foreign`)
    - Математика (:term:`mathematic`)

Пользователь направляет запрос (:term:`task_request`) на выполнение задания в рамках упражнения.

Приложение создает задание (:term:`task`).
Текущее задание конкретного пользователя идентифицируется по ID сессии упражнения (:term:`session_id`)
ID сессии упражнения не создается в приложении, поступает извне.

Идентификатор используется для временного сохранения/извлечения текущего задания:
    - при проверке ответа пользователя;
    - при добавлении/удалении изучаемого термина, слова в избранные (:term:`is_favorites`);
    - при изменении прогресса (:term:`progress`) знания изучаемого объекта;
    - в других случаях.

Пользователю направляется задание (:term:`task`), которое содержит вопрос (:term:`question`).
Некоторые типы задания предполагают получение от пользователя ответа (:term:`answer`).
Некоторые типы заданий могут содержать правильный ответ (:term:`answer_explanation`) на вопрос 
или варианты ответа (:term:`option`).

Приложение проверяет ответ пользователя на задание, если тип задания предполагает предоставление ответа.

Если ответ пользователя верен (:term:`correct_answer`), то:
    - пользователю предоставляется следующе задание (`task`)

Если ответ пользователя неверен (:term:`incorrect_answer`), то:
    - пользователю предоставляется объяснение правильного ответа (:term:`explanation`) в паре с вопросом.


Тип упражнения "Определение"
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Данный тип упражнения (:term:`definition_exercise`) подразумевает изучение слов и их значений,
например: терминов (:term:`term`), иностранных слов (:term:`translation`).


Тип упражнения "Вычисление"
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Данный тип упражнения (:term:`calculation_exercise`) подразумевает изучение слов и их значений,
например: терминов, иностранных слов.


Тип задания "Ввод ответа"
~~~~~~~~~~~~~~~~~~~~~~~~~

Задание типа "Ввод ответа" (:term:`answer_input`) подразумевает предоставление пользователю вопроса
и получение от пользователя введенного им ответа (текст, число).


Тип задания “Презентация”
~~~~~~~~~~~~~~~~~~~~~~~~~

Задание типа "Презентация" (:term:`presentation`) подразумевает предоставление пользователю вопроса 
и правильного ответа.


Тип задания “Тестирование”
~~~~~~~~~~~~~~~~~~~~~~~~~~

При выполнении задания типа "Тестирование" (:term:`testing`) пользователю
направляется вопрос (:term:`question_text`) и варианты ответа (:term:`option`).

Тест может содержать от 2 до 7 вариантов ответов.
Возможен только один правильный ответ на вопрос теста.

Вариант ответа (:term:`option`) представляет собой номер варианта (:term:`option_value`)
и текста варианта ответа (:term:`option_text`).

Ответ пользователя в тесте содержит номер варианта (:term:`option_value`).

Объект изучения
~~~~~~~~~~~~~~~
Пользователю предоставляется для изучение добавленные (сохраненные) объекты для изучения
(:term:`learnable`), например: термины, иностранные слова, а также, генерируемые
по определенным условиям (:term:`conditions`), например, вычисляемые по арифметическим действиям
(изучение таблицы умножения).

Прогресс и Уровень знания
~~~~~~~~~~~~~~~~~~~~~~~~~
Прогресс (:term:`option_value`) изучения объекта отслеживается изменением целочисленного значения
от 0 до 13. Размер максимального значение устанавливается по умолчанию,
может изменятся настройками пользователя. 

Уровень знания состоит из 4 стадий, со школой градации (по умолчанию):
    - изучаю (`study`), прогресс 0, ..., 5
    - повторяю (`repeat`), значение прогресса: 6, ..., 9
    - проверяю (`examine`), значение прогресса: 10, ..., 12
    - знаю (`know`), значение прогресса: 13
