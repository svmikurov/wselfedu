Glossary
========

.. glossary::

   exercise
       Упражнение, выполняемое пользователем.

   testing
       Упражнение в виде теста.

   question_text
       Текст вопроса

   options
       Варианты ответа, содержат номер вариант (:term:`option_value`) и текст варианта (:term:`option_text`) 

   option_value
       Номер варианта ответа в тесте.

   option_text
       Текст варианта ответа в тесте.
