Glossary
========

.. glossary::

   exercise
        Упражнение, выполняемое пользователем, состоит из заданий.

   glossary
        Дисциплина по изучению терминов.

   foreign
        Дисциплина по изучению иностранных языков.

   mathematic
        Дисциплина по изучению математики.

   definition_exercise
        Упражнение для изучения сохраненных слов (:term:`define`) и их объяснений (:term:`explain`),
        например: глоссарий, иностранный словарь.

   calculation_exercise
        Упражнение, предполагающее осуществление вычислений.

   define
        Термина или слова (словосочетание) на родном язык,
        в заданиях используемое как вопрос, по умолчанию.

   explain
        Толкование термина или перевод слова (словосочетание) на иностранный язык,
        в заданиях используемое как ответ, по умолчанию.

   term
        Термин для изучения, в дисциплине Глоссарий подразумевает
        наличие определения (:term:`define`) и
        наличие толкования (:term:`explain`).

   translation
        Слово или словосочетание для изучения, в дисциплине Иностранный язык подразумевает
        наличие слова на родном (:term:`define`) и
        наличие перевода слова на иностранный (:term:`explain`).

   task_request
         Запрос пользователя на формирование нового задания в упражнении.

   task
        Задание в рамках конкретного упражнения.

   answer_input
        Тип упражнения, при котором пользователю предоставляется вопрос
        и ожидается введенный им ответ (текст, число).

   presentation
        Тип упражнения, при котором пользователю предоставляется вопрос и ответ.

   testing
        Тип упражнения, при котором пользователю предоставляется вопрос
        и варианты ответа. От пользователя ожидается выбранным им вариант из предоставленных.

   session_id
        Идентификатор текущего задания для конкретного пользователя.

   question
        Вопрос из задания.

   answer_explanation
        Правильный ответ на вопрос, направляемый пользователю в задании вместе с вопросом.

   explanation
        Объяснение правильного ответа, содержит вопрос и ответ.

   answer
        Ответ пользователя на вопрос из задания упражнения. 

   correct_answer
        Результат проверки ответа пользователя, ответ верный.

   incorrect_answer
        Результат проверки ответа пользователя, ответ неверный.

   is_correct_answer
        Результат проверки ответа пользователя, является ли ответ верным.

   question_text
        Текст вопроса

   option
        Вариант ответа, содержат номер варианта (:term:`option_value`) и текст варианта (:term:`option_text`) 

   option_value
        Номер варианта ответа в тесте.

   option_text
        Текст варианта ответа в тесте.

   is_favorites
        Маркировка изучаемого объекта, используемая для фильтрации по условию.
 
   progress
         Прогресс изучаемого объекта, представлен целочисленным значение от 0 до 13 (по умолчанию)

   knowledge
         Уровень знания изучаемого объекта, имеет промежуточные стадии: изучаю, повторяю, проверяю, знаю.
